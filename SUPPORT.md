# Support

## Bugs

Use the repository's [bug report form](https://github.com/100xopensource/100x-credit-monitoring/issues/new?template=bug_report.yml) for reproducible unexpected behavior. Search existing issues first and use only synthetic examples.

## Feature requests

Use the [feature request form](https://github.com/100xopensource/100x-credit-monitoring/issues/new?template=feature_request.yml) to describe the user problem and smallest useful outcome.

## Security and confidential information

Do not put borrower documents, client identifiers, credentials, private incident details, or confidential financial information in a public issue. Report vulnerabilities and suspected confidential-data exposure through the private process in [SECURITY.md](SECURITY.md).

## Supported scope

The latest released version on Claude Cowork is supported. Current product boundaries are documented in [Supported today](README.md#supported-today) and [Limitations](docs/LIMITATIONS.md).

This open-source project does not provide a response-time or resolution-time guarantee. Maintainers may close requests that cannot be reproduced with synthetic information or fall outside the documented scope.
