Credit Monitoring setup

Getting your folders ready

Start here

Choose where your two folders live

Credit Monitoring works directly with folders already on your computer, including folders synced through OneDrive, SharePoint, or Google Drive for desktop. There is nothing to upload or migrate. Keep both local for the simplest setup, or use a synced provider for the source, output parent, or both.

Credit Monitoring needs access to two separate folders:

  • a source folder containing borrower documents, which the plugin reads but does not modify;
  • an output parent folder, where the plugin creates or reconnects credit-monitoring-output.

Recommended

Keep both folders local

No cloud account or sync setup is required.

Before you begin

  • A local folder containing borrower documents.
  • A separate writable local output parent.
1

Approve the source request

When Cowork asks, choose Choose folder. The next window is for the borrower documents.

2

Choose the borrower documents

Select the source folder through the folder picker. Do not type or paste a path.

3

Choose the output parent

Approve the next request and select a separate local folder for results. Select the parent—not credit-monitoring-output.

4

Let Credit Monitoring prepare the store

The plugin creates or reconnects credit-monitoring-output beneath the parent. Use separate sibling folders or otherwise separate locations; neither selected folder may contain the other. A new Cowork session may ask you to approve them again.

Ready whenBoth folders are available in Cowork and credit-monitoring-output exists beneath the selected output parent.
SafetyIf an existing credit-monitoring-output contains unknown or malformed data, Credit Monitoring leaves it unchanged. Choose another parent, review the files yourself, or stop.

Synced Microsoft folders

Use OneDrive for one or both folders

The source, output parent, or both may be in personal OneDrive. Organization-provided SharePoint folders work the same way once OneDrive exposes them on the computer.

Before you begin

  • OneDrive installed, signed in, and running.
  • Read access to the synced source and write access to the synced output parent.
  • Enough disk space for every folder kept locally.

Use OneDrive under Finder or File Explorer. Do not type or publish the account-specific storage path.

1

Find the folders on your computer

Open OneDrive and locate whichever folder will be the source, output parent, or both.

2

Keep every synced folder local

Right-click each folder used by Credit Monitoring and choose Always keep on this device. This pins a local copy; OneDrive already handles synchronization. Wait for downloading to finish.

online onlysyncingavailable locally
3

Approve the source in Cowork

Choose the folder containing borrower documents. It may be local or synced and Credit Monitoring never changes it.

4

Approve the output parent

Choose a separate writable folder. Separate sibling folders beneath one OneDrive parent are fine; neither selected folder may contain the other.

5

Let Credit Monitoring prepare the store

The plugin creates or reconnects credit-monitoring-output beneath the selected output parent.

Ready whenEvery synced folder is locally available, approved in Cowork, and the selected output parent contains credit-monitoring-output after setup.
SafetyChanging offline availability later can make files unreadable to Cowork. Do not delete a synced folder merely to disconnect it.

Synced Google folders

Use Google Drive for one or both folders

The source, output parent, or both may be in Google Drive for desktop.

Before you begin

  • Google Drive for desktop installed, signed in, and running.
  • The source must be locally readable; the output parent must also be writable.
  • Both folders must be locally available through Finder or File Explorer.

Credit Monitoring uses the folder exposed on your computer, not a Google Drive web URL or API. Do not type or publish the account-specific storage path.

1

Find the folders on your computer

Open Google Drive in Finder or File Explorer and locate whichever folder will be the source, output parent, or both.

2

Keep every synced folder local

Right-click each streamed folder used by Credit Monitoring and choose Make available offline. This pins a local copy; Drive for desktop already handles synchronization. Mirrored folders are already local. Wait for downloading to finish.

3

Approve the source in Cowork

Choose the folder containing borrower documents. It may be local or synced and Credit Monitoring never changes it.

4

Approve the output parent

Choose a separate writable folder. Separate sibling folders beneath one Google Drive parent are fine; neither selected folder may contain the other.

5

Let Credit Monitoring prepare the store

The plugin creates or reconnects credit-monitoring-output beneath the selected output parent.

Ready whenEvery synced folder is locally available, approved in Cowork, and the selected output parent contains credit-monitoring-output after setup.
SafetyChanging offline availability later can make files unreadable to Cowork. Do not delete a synced folder merely to disconnect it.
Troubleshooting: If Cowork sees a filename but cannot read it, ensure Drive has downloaded it locally before retrying.

Stuck? Stop and describe what you see. Credit Monitoring never overwrites unknown existing data or falls back to a temporary output folder.
