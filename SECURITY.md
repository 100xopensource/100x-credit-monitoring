# Security policy

## Supported version

Security fixes target the latest released version.

## Report privately

Do not open a public issue for a suspected vulnerability, confidential-data exposure, credential, or borrower-specific finding.

Use GitHub's private **[Report a vulnerability](https://github.com/100xopensource/100x-credit-monitoring/security/advisories/new)** form.

Include only a minimal reproduction, affected version, and impact. Do not attach real borrower documents or secrets; use synthetic examples or request a private transfer method. Do not disclose the issue publicly while it is being reviewed.
